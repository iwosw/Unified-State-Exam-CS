Учебный сайт по заданиям **1–27 ЕГЭ по информатике**. На главной — каталог и поиск; у каждого номера — собственная страница с краткой теорией, алгоритмом решения, запускаемым Python-разбором и кодовым каркасом на Python, Java, C++ и Rust. Примеры по фотографиям находятся **внутри соответствующих заданий**, а не в отдельном каталоге.

## Быстрый старт

1. [Открой сайт](https://iwosw.github.io/Unified-State-Exam-CS/) или открой `index.html` локально в браузере.
2. Выбери номер через каталог или поиск, например [№8 — комбинаторика](https://iwosw.github.io/Unified-State-Exam-CS/tasks/08.html) или [№16 — рекурсия](https://iwosw.github.io/Unified-State-Exam-CS/tasks/16.html).
3. Прочитай шаги и контрольный ответ. Скопируй **полный пример на Python** в `solution.py`, запусти в PyCharm либо через `python solution.py` (на некоторых системах — `python3 solution.py`). Нужен Python 3.10+; дополнительные пакеты не требуются.
4. Сверь вывод с ответом на странице, затем поменяй исходные данные и условия под свой вариант.

## Что на странице задания

- Что обычно дано в условии и какой результат ожидается.
- Пошаговый алгоритм и отдельный разобранный пример с проверенным ответом.
- Другие варианты этой же темы из присланных фото, когда они есть: №1, 2, 8, 14, 16 и 25. Нечёткие условия на двух фото помечены как учебные адаптации.
- Переключение языка для **шаблона**, который нужно приспособить к конкретной формулировке. Полностью запускаемый Python-код находится в блоке разбора.
- Ссылки на соседние номера и быстрый переход по всем 27 заданиям.

В шаблонах с `open('17.txt')`, `open('24.txt')` и другими файлами положи входные файлы в рабочую папку Python. Для `.xlsx` экспортируй нужный лист в CSV или адаптируй чтение. Все полные примеры разбора запускаются **без входных файлов**.

## Проверка

Для локальной проверки нужен Node.js и установленный Python:

```sh
node check-python-examples.js
```

Скрипт сверяет вывод **27 разборов и 9 примеров с фото**, проверяет синтаксис и пробный запуск 25 уникальных Python-шаблонов. Файловые шаблоны получают временные учебные данные. Шаблоны Java, C++ и Rust этим скриптом не проверяются.

## Структура

```text
index.html                каталог и поиск
tasks/01.html … 27.html   отдельные страницы заданий
catalog.js                карточки, фильтры и поиск
task-page.js              наполнение страницы задания
app.js                    темы и шаблоны по 27 номерам
walkthroughs.js           пошаговые Python-разборы
python-examples.js        дополнительные варианты с фото
styles.css                оформление
check-python-examples.js  проверка кода
assets/                   иллюстрации
```

Сайт статический: сборщик и сервер для просмотра не нужны. Публикация через [GitHub Actions](.github/workflows/deploy-pages.yml) происходит при обновлении `main`.
