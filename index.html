Как использовать

У каждого номера — своя страница

1. Найди номер

Выбирай карточку или переходи напрямую по номеру. Поиск работает и по темам примеров с фото.

2. Смотри паттерн

На странице номера есть условие, шаги, пример с ответом и советы для своего варианта.

3. Переключай язык

На странице номера можно переключать шаблоны на Python, Java, C++ и Rust. Фото-коды лежат рядом с разбором.

У каждого из 27 заданий есть постоянная ссылка. Разборы на Python можно запустить без файлов; шаблоны на четырёх языках нужно адаптировать под конкретный вариант.
